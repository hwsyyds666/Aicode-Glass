# 三种模式：Build / Plan / Ask

输入框左侧的模式按钮点击循环切换：BUILD → PLAN → ASK → BUILD。模式定义工作方式；具体工具授权由授权挡位与专项安全规则决定。

## BUILD（构建模式）

功能完整，适合直接执行明确的开发任务。文件写入、命令、网络等操作按当前授权挡位判断；删除命令始终逐次确认，受保护目标不可放行。

## PLAN（计划模式）

PLAN 会先把多步骤工作拆成可见计划，再按顺序自动实施并持续更新每一步的进行中、完成或失败状态。计划清单使用会话待办卡片展示，方案变化时也应同步更新。

PLAN 不再是只读沙盒，也不额外扩大权限：它与 BUILD 使用相同工具集和授权挡位。规则拦截、自主审查、完全权限、删除专项授权及其硬拦截都照常生效。默认不在计划完成后额外等待“批准计划”面板；模式退出只恢复进入 PLAN 前的模式。

适用于目标明确、包含多个依赖步骤且希望 AI 连续完成的工作。如果想讨论方案但不允许执行任何写操作，请使用 ASK。

## ASK（提问模式）

只读问答与探索。写操作及 AI 自行切换模式仍由系统硬拒绝；需要实施时由用户切换到 PLAN 或 BUILD。

## AI 主动切换模式

AI 可通过 `planMode` 请求进入或退出 PLAN。退出时恢复进入前模式（从 BUILD 进入则回 BUILD，从 ASK 进入则回 ASK）；模式切换不再弹出计划批准闸门。实际工具调用仍按照当前模式和授权设置裁决。用户也可以在运行中手动切换模式，切换从后续工具调用起生效。
