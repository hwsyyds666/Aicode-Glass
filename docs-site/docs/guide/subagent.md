# 子代理

子代理是在主会话之外运行的独立任务会话。它有单独的消息历史、模型调用记录、状态和工具范围；完成或失败后会通知主会话。只有用户在当前会话打开「超级 Agent」，或在请求中明确要求派发时，主代理才可以创建子代理。

子代理适合目标独立、边界清晰且并行收益高的调研或实现。简单、强耦合或需要频繁共享决策的工作由主代理完成；并行调用会增加 token 与审查成本，不应为了并行而拆分。

## 内置类型

| 类型 | 可用能力 | 适用场景 |
| --- | --- | --- |
| `explore` | 只读本地文件与技能；不联网、不执行命令、不写文件 | 追踪代码入口、调用链与模块关系。可选快速、普通或彻底检查深度 |
| `research` | 仅网页搜索和抓取；不能读取本地文件或运行命令 | 核对官方文档、版本行为和外部事实。网页内容均视为不可信数据 |
| `worker` | 在声明的工作区可写范围内使用文件工具修改；shell 仅允许静态安全只读命令，以及受限的 Gradle test/check/lint/assemble 任务 | 实现边界明确的代码变更。受限构建任务必须从可写范围根目录执行，并显式选择 container 或 remote 环境 |
| `reviewer` | 只读本地文件；没有命令执行或写入能力 | 对照原始需求和 diff 独立找遗漏、回归或安全问题 |

类型、系统提示词和工具权限由应用内置定义，旧版自定义 `.md` 子代理文件保留在原位置但不再加载。首次发现旧定义时应用会提示迁移；Explore 的旧模型选择会迁移到快速档，其它自定义类型的模型配置不会迁移。

## 派发与审查

开启超级 Agent 后，主代理会先理解需求，再把适合并行的工作拆成互不重叠的任务。每项派发都必须包含目标背景、可写/只读范围、共同约束、禁止事项、验收标准和返回格式；缺任一项会被工具拒绝。子代理不能嵌套，运行数量、单个父会话累计数量和超时均有上限。

`worker` 必须声明工作区内的可写路径。文件工具会在执行前校验目标范围，重叠的运行中写入范围不能并行。shell 子进程无法由应用对任意脚本做可靠的逐文件沙箱，因此 worker 只能通过受限入口运行标准 Gradle test/check/lint/assemble 任务；脚本、重定向、父目录遍历和 device 环境均拒绝。其它 shell 只开放静态安全只读命令。读、写或命令授权仍受主会话的权限策略约束，不能借子代理提高权限。

主代理必须读取子代理结果、核对实际差异和验收标准；必要时给出精准返工，最多两轮。大型或高风险改动可再派只读 reviewer 独立核对原始需求与差异，审查输入不包含主代理的私有推理。

超级 Agent 开关按会话保存，新建会话默认关闭；切换开关只影响后续请求，已经开始的任务不会中途改变权限或模型。快速档供 Explore/Research 使用，主力档供 Worker/Reviewer 使用；每档可跟随当前主会话模型，也可单独选择供应商、模型与思考强度。

## 会话与检查点

子代理的 token 调用记录会归入工作区用量统计。子会话会显示负责类型、范围、生命周期状态和结果；可从聊天卡片或侧栏进入查看。停止父任务会取消其派生会话；超时、停止和失败会更新持久状态并通知父会话。

回退或删除包含子代理输出的消息轮次时，应用会先停止并等待相关工作流，再还原对应检查点、清除后续子会话/待办/检查点并使会话上下文重建。若当前目录没有 Git 快照或大文件超过快照上限，回退提示会说明命令行改动可能无法完整还原；文件工具的单文件检查点仍会尽量作为回退补充。用量记录保留供统计查看。

如需检查授权弹窗来源，子代理发起的请求会标明类型和任务标题。子代理看不到主会话的私有推理历史；创建时必须把完成任务所需的信息写进自包含交接。
